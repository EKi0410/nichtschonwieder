# Anhang A — Der Bewertungsbogen

Dieses Raster hat hundert Modelle bewertet. Ab hier bewertet es deine.

Es ist zum Kopieren gedacht — auf ein Blatt, in eine Tabelle, wohin du willst.
**Zwanzig Minuten je Idee.** Wer es dreimal ausgefüllt hat, braucht das Blatt
nicht mehr und hat die Fragen im Kopf. Das ist der Punkt, an dem dieses Buch
seine Aufgabe erfüllt hat.

---

## Teil 1 — Die Vorprüfung

Fünf Fragen. **Wenn eine davon mit nein beantwortet wird, ist die Bewertung
nicht nötig.**

| # | Frage | Antwort |
|---|---|---|
| 1 | Kannst du drei Unternehmen mit Namen nennen, die dieses Problem haben? | |
| 2 | Kannst du benennen, was dieses Problem sie im Jahr kostet — in Euro? | |
| 3 | Weißt du, wen du dafür anrufen würdest, und hast du die Nummer? | |
| 4 | Gibt es einen Grund, warum ausgerechnet du das anbieten kannst? | |
| 5 | Kannst du die erste Version verkaufen, bevor du irgendetwas gebaut hast? | |

*Zu 4: Nischenkenntnis, ein Zugang, eine Qualifikation, eine schwierige
Beschaffung oder ein Service, den sonst niemand liefert. „Ich mache es besser"
ist kein Grund.*

## Teil 2 — Die acht Dimensionen

Ein bis fünf Sterne, und **zu jedem Stern ein Satz, warum**. Ein Stern ohne
Begründung ist ein Gefühl.

| Dimension | Gewicht | Sterne | Begründung in einem Satz |
|---|---:|---|---|
| **Monetarisierung** — ist der Preis durchsetzbar und nicht öffentlich vergleichbar? | 15 % | | |
| **Vertrieb** — gibt es einen benennbaren ersten Vertriebsweg mit Anlass? | 20 % | | |
| **Upsell-Potenzial** — was kannst du demselben Kunden danach verkaufen? | 5 % | | |
| **Wiederkehrender Umsatz** — kommt das Geld ohne neuen Verkauf wieder? | 15 % | | |
| **Skalierbarkeit** — wächst der Umsatz schneller als die Arbeit? | 15 % | | |
| **Kapitalleichtigkeit** — was kostet der Anfang, und was bindet Geld? | 5 % | | |
| **Marge** — was bleibt nach allen Kosten und deiner eigenen Zeit? | 15 % | | |
| **Wettbewerbsposition** — was hält jemanden davon ab, es dir nachzumachen? | 10 % | | |

### Die Rechnung

**Note = (Summe aus Sterne × Gewicht) × 2**

Beispiel: 4·0,15 + 3·0,20 + 4·0,05 + 5·0,15 + 4·0,15 + 5·0,05 + 4·0,15 + 3·0,10
= 4,00 → **Note 8,0**

### Die Korrektur

**Höchstens ein Punkt nach oben oder unten** — und nur mit einem Grund, der in
keiner der acht Boxen steht.

Zulässige Gründe, alle aus diesem Buch: ein Haftungsrisiko, das über den
normalen Betrieb hinausgeht · eine Abhängigkeit von einem einzelnen Menschen,
Anbieter oder Förderprogramm · ein Markt, der schrumpft · eine Reihenfolge, in
der Kapital und Auftrag sich gegenseitig bedingen · ein Fehler, der nicht
korrigierbar ist · eine Marktseite, die gegenläufig zur anderen schwankt.

**Unzulässig:** eine Dimension zweimal bestrafen. Wenn die Kapitalbindung schon
bei der Kapitalleichtigkeit steht, ist sie kein Korrekturgrund.

Wo steigst du ein, und wo hörst du auf?

```
1 Problem  →  2 Dienstleistung  →  3 produktisierte Dienstleistung  →
4 wiederkehrender Umsatz  →  5 Automatisierung  →  6 Software  →  7 Plattform
```

| | Antwort |
|---|---|
| Einstiegsstufe | |
| Zielstufe | |
| **Wo bricht die Kette ab — und warum?** | |

### Der Dreifachtest vor jeder Stufe 6

Alle drei müssen erfüllt sein. **Zwei genügen nicht.**

| | ja / nein |
|---|---|
| Habe ich dieses Problem in meiner eigenen Dienstleistung oft genug selbst gelöst? | |
| Existiert der Vertriebsweg schon — habe ich bestehende Kunden? | |
| Entlastet die Software meinen Betrieb so, dass sie sich auch ohne einen einzigen Fremdkunden rechnet? | |

*Wenn einer fehlt: Die Dienstleistung ist das bessere Geschäft. Vibecoding hat
die Herstellungskosten gegen null gedrückt — an Betrieb, Support, Sicherheit
und Vertrieb hat es nichts geändert.*

## Teil 4 — Die Rechnung, die man nicht überspringt

| | Betrag |
|---|---|
| Preis je Einheit (Vorgang, Objekt, Monat, Mitarbeiter …) | |
| Nötige Menge für 3.000 € Ergebnis im Monat | |
| Direkte Kosten je Einheit | |
| Fixkosten im Monat (inklusive deiner Lebenshaltung) | |
| **Deckungsgrad der Fixkosten durch wiederkehrenden Umsatz** | **%** |
| Startkapital, ehrlich gerechnet | |
| Monate bis zum ersten Euro | |
| **Ergebnis bei 80 % der geplanten Auslastung** | |

*Die letzte Zeile ist die wichtigste. Wenn es bei achtzig Prozent nicht trägt,
ist es kein Geschäftsmodell, sondern eine Wette auf Vollbelegung.*

## Teil 5 — Die Haftungsfrage

Nur bei Modellen, deren Nachfrage aus einer Pflicht kommt. **Regulierung als
Nachfragetreiber ist etwas anderes als Regulierung als eigenes Risiko.**

| | Antwort |
|---|---|
| Wer haftet, wenn die Pflicht verletzt wird — der Kunde oder ich? | |
| Werde ich als Beauftragter benannt, oder liefere ich Dokumentation? | |
| Welches Vertragskonstrukt begrenzt das Risiko? | |
| Welche Versicherung deckt es — und deckt sie es wirklich? | |

*Wer Dokumentation aufbaut und übergibt, verkauft an einem Pflichtmarkt, ohne
die Pflicht zu übernehmen. Wer sich bestellen lässt, haftet persönlich für die
Pflicht eines anderen. Derselbe Markt, ein völlig anderes Risiko — und der
Unterschied ist eine Unterschrift.*

---

## Teil 6 — Das Abbruchkriterium

**Vor dem ersten Anruf ausfüllen. Nicht danach.**

> Bis zum **_____________** habe ich **_____** Entscheider gesprochen,
> **_____** Angebote abgegeben und **_____** € vereinnahmt.
>
> Wenn das nicht erreicht ist, mache ich **_______________________________**
> und nicht weiter mit diesem Modell.

*Der zweite Satz ist der wichtigere. Ein Abbruch ohne Nachfolger führt zurück in
die Suche — und aus der wolltest du raus.*

---

## Und die drei Fragen, die alles ersetzen, wenn es schnell gehen muss

1. **Wer bezahlt, wie oft, und wofür genau?**
2. **Warum ausgerechnet du — und warum nicht jemand, der es billiger kann?**
3. **Was bleibt übrig, wenn du drei Monate nichts verkaufst?**

Wer diese drei Fragen zu einer Idee beantworten kann, braucht das Blatt nicht.
