# Anhang C — Drei Register

eigentliche Nachschlagefunktion dieses Buches: Wer eine Bedingung hat — Geld,
Branche oder Bewertung —, findet hier die Kapitel, die dazu passen, ohne die
Matrix zu durchsuchen.

(Teil III, Kapitel 1).
