# Buchprojekt: „Vom Geschäftsmodell zum Unternehmen"

Arbeitsverzeichnis für ein Business-Sachbuch mit rund 480 Seiten und 100
konkreten Geschäftsmodellen, jedes in voller analytischer Tiefe.

## Dateien

| Datei | Inhalt |
|---|---|
| `01-bucharchitektur.md` | Titel, Zielgruppe, Versprechen, Positionierung, Gesamtstruktur, Inhaltsverzeichnis, Seitenplanung |
| `02-modellkatalog.md` | Kategorien, vollständige Liste der 100 Geschäftsmodelle, Reihenfolge, Kapitelrollen |
| `03-kapitelvorlage-bewertungssystem.md` | Standardstruktur eines Modell-Kapitels, Bewertungssystem, Business-Boxen, Coaching-Integration |
| `04-voice-bible.md` | Redaktionelle Leitlinien, Autorenstimme, Verbotsliste, Fragebogen an den Autor |
| `05-recherche-backlog.md` | Alle Punkte, die vor Drucklegung faktisch verifiziert werden müssen |
| `STATUS.md` | Projektfortschritt, wird nach jedem finalisierten Kapitel aktualisiert |

## Arbeitsprozess

Phase 1 — **Architektur** (dieser Stand). Keine Kapitel, nur Fundament.
Phase 2 — **Kapitelentwicklung**, immer nur ein Kapitel gleichzeitig, in sieben
Iterationen bis `STATUS: DRUCKFREIGEGEBEN`.
Phase 3 — **Gesamtdurchsicht**, Konsistenz der Bewertungen, Redundanzcheck,
Satz.

Der Ablauf der sieben Iterationen ist in `03-kapitelvorlage-bewertungssystem.md`,
Abschnitt 7, beschrieben.

## Entscheidungen

Getroffen: alle 100 Modelle in voller Tiefe (Variante C), Sterne-Skala
durchgehend positiv. Offen: Titelwahl und Autorenmaterial — siehe
`01-bucharchitektur.md`, Abschnitte 11 und 12.
